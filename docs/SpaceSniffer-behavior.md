# SpaceSniffer 行为核对与实现边界

核对对象：用户本机 SpaceSniffer 1.3.0.2；实际查看了 Geometry、Animation 配置页，随后按 Cancel 退出，没有改动原版配置或程序。

## 有原始资料支持的行为

- 细节控制递归展开深度；单击可查看更深内容，双击缩放进入目录。扫描时也可导航。[作者产品说明](https://www.uderzo.it/main_products/space_sniffer/)
- 扫描缓存与文件系统事件连接，外部变化可更新视图；缓存供视图复用。[作者功能说明](https://www.uderzo.it/main_products/space_sniffer/features.html)
- 最小元素尺寸、初始层级、动画频率是独立选项。DynaSmooth 在交互时提高频率、空闲时降低；没有新信息时不刷新。[作者手册，4、5、8 节（原文镜像）](https://people.stfx.ca/dmattie/spacesniffer_1_1_3_1/SpaceSniffer%20User%20Manual.pdf)

这些资料说明公开行为，不代表已获得原版源码。未证实原版具体排布实现、线程队列结构或绘图 API，不能把本项目算法说成原版内部算法。

## 本项目修正

1. 数据树保存完整扫描结果；视图裁剪不修改字节总量。取消“固定保留 24 个孩子”和有名字的合并项目。
2. 默认层级由 QueryOptions.MapDepth 决定；单击目录仅显示其直接子项；点父目录名称条收起更深内容，并覆盖该子树较早的展开状态，双击进入。工具栏 − / ＋ 恢复统一层级。删除渲染器按可见面积比例自动收拢目录的规则。预算控制横向显示数量，不能提前耗尽后令后面的同级目录少展开一层。
3. 本项目选择在省略不可读细项后重新排布可见项，消除合并余量带来的大空白；该选择是实现设计，不冒称已验证的原版内部步骤。目录标签保持完整总量，界面提示与说明明确可见项归一化比例。
4. 原先在界面线程构建全部文字和布局，1056 个带字方块连续更新时输入等待达到 104–192 ms。改为单个后台绘制任务、固定容量字形缓存、冻结图形交回界面；合并过期请求，无变化时不重画。
5. 首次扫描持续提供预览，交互、空闲、非活动窗口与最小化分别使用不同刷新间隔。完整结果到达后继续使用文件变化通知，合并突发事件，只更新相关路径；通知溢出时后台校准。

## 未宣称等同原版的部分

尚未实现多视图共享扫描、扫描时任意目录内导航、选区优先子扫描、NTFS ADS 或实际分配字节统计。本项目默认逻辑字节统计；精确范围和限制见 README。

## 验证入口

- `build.ps1 -Test`：真实文件通知、聚合、取消、权限、视图层级和面积检查。
- `--verify-render <目录>`：1056 方块连续绘制的输入延迟、帧完成数量、相同数据不重画、密集与稀疏目录同层展开。
- `--verify-interactions <目录>`：单击局部展开、展开后双击目标、提示框关闭与重新定位、选中不改变空间图高度。
- `--verify-ui <目录>`：真实 WPF 控件、文件变化、D 盘扫描预览、导航、筛选、深浅主题与实际内容截图。
