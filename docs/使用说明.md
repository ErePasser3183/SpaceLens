# 快捷键

| 快捷键 | 任务管理器 | 磁盘空间 |
| --- | --- | --- |
| Ctrl+F | 搜索 | 搜索 |
| F5 | 刷新 | 重新扫描 |
| F8 | 显示 / 隐藏列表 | 显示 / 隐藏列表 |
| Alt+← / Alt+→ | 后退 / 前进 | 后退 / 前进 |
| Alt+↑ | 返回全部进程 | 上一级 |
| Alt+Home | 返回全部进程 | 根目录 |
| Esc | — | 停止扫描 |

内存优化功能参考了龙腾猫跃的 PCL2 启动器中的相关功能。

设置 → 自动更新：后台下载，关闭后更新，下次启动生效。也可选择“检查更新”。
