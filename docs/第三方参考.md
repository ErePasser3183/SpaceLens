# 内存优化参考

内存优化的 Windows 调用顺序参考 **Plain Craft Launcher（PCL）**，作者 **龙腾猫跃及 PCL 贡献者**。

- 项目：https://github.com/Meloong-Git/PCL
- 参考版本：PCL Snapshot 2.99.0.0。
- 参考位置：Snapshot 源码中的 `PCL/PageOtherTest.cs`，`MemoryOptimize` / `MemoryOptimizeInternal`。
- 参考项目的 `LICENCE` 和合理使用说明；许可链接：https://shimo.im/docs/rGrd8pY8xWkt6ryW#anchor-X0bo 。

SpaceLens 是独立的磁盘与进程查看工具，与 PCL 官方无关联。仅参考系统内存整理与下载模块的部分流程，不包含 Minecraft 启动、资源下载业务或 PCL 界面资源。

PCL 原流程启用 `SeProfileSingleProcessPrivilege`，调用 `NtSetSystemInformation(SystemMemoryListInformation = 80)` 的命令 2、3、4：修剪进程驻留内存、刷新已修改页、清理待机页。它改变的是页面驻留和缓存状态，不会释放应用仍在使用的虚拟内存分配，也不能修复泄漏。

SpaceLens 的改进：

- 用户点击后即请求管理员辅助进程执行命令 2，不再以 Windows 的紧急低内存通知作为是否执行的门槛。
- 命令 2 后同时检查 Windows 低内存通知和实际可用物理内存，避免高占用尚未触发系统警报时误判。
- 执行命令 2 后，若系统仍报警、内存占用达到 80% 或可用内存不超过 1 GiB，再执行命令 3；否则结束。任一步失败保留原始错误码并停止后续操作，结束后恢复令牌权限。
- 移除命令 4：待机页本来计入可用内存，可以被 Windows 回收，清空它可能丢弃后续会用到的缓存。保留待机缓存旨在减少无必要的重新读取，并非已测得的性能提升。
- 同一登录会话中用互斥量防止多个辅助进程同时整理内存；同一窗口继续防止重复点击。

主界面继续采样。辅助入口只接受固定参数，不接受任意文件路径或命令。取消授权、系统不支持或权限不足都会恢复按钮并显示结果。效果按整机可用物理内存前后差值显示，可能为负，也受其他程序活动影响。即使有低内存信号，系统级驻留页修剪仍可能影响前台程序；Windows 自身也会管理内存，这个手动功能不能保证加速。未进行高内存压力下的端到端清理或性能对比。

API 校对：
- [AdjustTokenPrivileges（Microsoft）](https://learn.microsoft.com/windows/win32/api/securitybaseapi/nf-securitybaseapi-adjusttokenprivileges)：成功返回仍须检查 ERROR_NOT_ALL_ASSIGNED。
- [System Informer 的原生内存命令定义](https://github.com/winsiderss/phnt/blob/master/ntexapi.h)：SYSTEM_MEMORY_LIST_COMMAND。
- [Microsoft：Working Set](https://learn.microsoft.com/en-us/windows/win32/memory/working-set)：驻留页、缺页与已修改页写回。
- [Microsoft：Memory Footprint 指标](https://learn.microsoft.com/en-us/windows-hardware/test/assessments/results-for-the-memory-footprint-assessment)：Available Memory 包括 Standby Memory。
- [Microsoft：CreateMemoryResourceNotification](https://learn.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-creatememoryresourcenotification)：系统低内存通知，未处于低内存或高内存状态时应保持内存使用。
- [Microsoft：QueryMemoryResourceNotification](https://learn.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-querymemoryresourcenotification)：无阻塞查询。

自动检查覆盖低内存与健康状态、状态恢复时提前结束、查询失败时不继续刷新已修改页、原生错误中止、Windows 通知读取、权限获取/恢复、正负测量值、界面忙碌/防重复、无变化、取消和失败恢复。自动界面检查使用替身执行器，不进行整机内存清理。使用说明仅包含操作方法，署名及技术说明集中保留在本文件。

## 下载模块参考

更新下载器的分段请求、并行工作线程、失败重试、不支持 Range 时退回单流、分段合并后校验流程，参考龙腾猫跃及 PCL 贡献者的公开源码 Plain Craft Launcher 2/Modules/Base/ModNet.vb（NetFile / NetThread）。Snapshot 工具箱 StartCustomDownload 也调用这一公共下载模块。
